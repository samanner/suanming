# 玄学命理馆 · 项目文档

> 版本 v0.1 ｜ 最后更新：2026-10-13
> 一句话介绍：输入生辰，自动排出八字 + 紫微斗数双盘，做三术交叉验证，并能一键生成"AI深度解读指令"的本地网页应用。所有计算都在你自己电脑上完成，不上传任何数据。

---

## 一、怎么启动

| 方式 | 操作 |
|---|---|
| 一键启动 | 双击桌面 **启动-玄学命理馆.bat**（自动起服务+开浏览器） |
| 电脑直访 | 浏览器输入 `http://localhost:8931/suanming/` |
| 手机测试 | 手机连同一WiFi，浏览器输入 `http://192.168.1.31:8931/suanming/` |

- 服务是后台运行的 PowerShell 小程序（端口8931），关掉窗口不影响，重启电脑后双击 bat 即可
- 同一个服务还挂着"诸神空间"游戏：`http://localhost:8931/`

## 二、整体架构（三层）

```
┌─ 界面层 ─ 一个网页文件 index.html
│   深色国风界面，三个页签：八字命盘 / 紫微斗数 / 三术合参
│
├─ 排盘引擎层 ─ 两个业界标准开源库（已本地化，断网也能用）
│   · lunar-javascript → 八字（四柱、十神、藏干、五行、大运）
│   · iztro            → 紫微斗数（12宫、星曜、四化、五行局）
│
└─ 服务层 ─ 一个迷你HTTP服务 serve.ps1
    把上面两层以网页形式供出来，电脑手机都能访问
```

**为什么选这两个库：** 它们是命理软件圈最广泛使用的排盘引擎，天文历算（节气、朔望月、干支纪年）由它们处理，我们只做展示和解读，不自己算历法——自己算容易错，这两个库经过海量命例验证。

## 三、功能清单与实现原理

### 1. 八字命盘页
输入阳历/农历生辰（精确到分钟），引擎自动完成：
- **排四柱**：年柱、月柱、日柱、时柱。月柱按节气切换（如立春才算正月），不是按农历初一——这是专业和业余的分水岭
- **十神**：以日干代表"你自己"，其他七字与它的五行生克关系换算成十神（比肩、劫财、食神…正官、七杀），是八字解读的核心语言
- **藏干**：每个地支里藏着1-3个天干，列表已分行显示
- **纳音**：古法五行分类，标注在干支下方
- **五行气数统计**：统计八个字（含藏干）中金木水火土各出现几次，画成条形图
- **旺衰判定**：先看日主（日干）五行占比——超过35%算"偏旺"，低于25%算"偏弱"，之间算"中和"；再结合得令、得地、得势判断身强身弱，给出喜用神建议
- **大运排盘**：按性别和年干阴阳决定顺排/逆排，从月柱推出未来每十年的大运干支，标注起运岁数

### 2. 紫微斗数页
- **安星排盘**：根据农历生日+时辰，排出12宫（命宫、兄弟、夫妻、子女、财帛、疾厄、迁移、仆役、官禄、田宅、福德、父母）每宫的主星、辅星
- **命宫高亮**：金框标出命宫，蓝框标出身宫
- **四化标记**：出生年干带来的禄、权、科、忌四颗变化星，用徽章显示
- **宫干四化**：每宫宫干飞出的四化也标在宫名旁
- **五行局**：如水二局、木三局…决定紫微星落地位置，页头展示
- 注意：必须填时辰，没有时辰紫微无法定位，按钮会自动禁用并提示

### 3. 三术合参页（本项目的灵魂）
单独看八字或紫微都容易片面，这一页把两套系统的结论交叉比对：
- **性格画像**：八字日主性格 × 紫微命宫主星性格，双视角描述
- **事业财向**：八字看官星财星 vs 紫微看官禄宫、财帛宫主星
- **感情模式**：八字看配偶星 vs 紫微看夫妻宫
- **交叉验证**：两套系统结论一致标"✓ 两术同参"，有出入就直说"◐ 视角不同"——命理本来就有多个观察角度，不硬凑
- **AI深度解读指令**：一键生成一段结构化的提示词（包含命盘全部关键数据），复制发给 Kimi 或任意 AI，就能收到1500字以上的详细批命。这是"传统排盘 + 现代大模型"的玩法：机器保证排盘准确，AI负责语言解读
- **导出命书**：把解读指令存成 .txt 文件

## 四、术语速查（读懂盘面）

| 术语 | 意思 |
|---|---|
| 日主/日元 | 日柱天干，代表命主本人 |
| 十神 | 其他字与日主的关系：生我者为印，我生者为食伤，克我者为官杀，我克者为财，同我者为比劫 |
| 藏干 | 地支内部暗藏的天干 |
| 身强/身弱 | 日主五行在全局的强弱，弱则需印比帮扶（喜用），强则需泄耗（忌） |
| 大运 | 十年一换的运势阶段 |
| 命宫 | 紫微12宫的核心，代表先天格局 |
| 四化 | 禄（福）、权（权）、科（名）、忌（阻），随出生年干飞布 |
| 五行局 | 紫微定盘基础，由命宫干支推出 |
